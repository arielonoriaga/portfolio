# portfolio

Personal site of Ariel Onoriaga, senior Rust / TypeScript engineer. One static page built with Astro, no client-side JavaScript.

```bash
bun install
bun run dev      # local preview
bun run build    # output in dist/
```

Content lives in `src/pages/index.astro`. Pushing to `main` deploys to GitHub Pages.

The earlier Three.js experiment is kept on the `yggdrasil-experiment` branch.
